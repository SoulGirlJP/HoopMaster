\# HoopMaster - Simple Basketball Gameplay

This project is a simple, single net, Basketball game containing many neat features.

## Content / Features



### First-person movement

* Mouse look
* Sprinting with acceleration
* Dynamic Field of View (FOV) based on movement speed
* Jumping with the faster you go, the higher you jump mechanic
* Player reset system



### Basketball Mechanics

* Ball pickup system
* Hold point system
* Charge throwing
* Different throw forces
* Dribbling mechanic
* Ball reset system
* Physics basketball interactions
* Ground collision handling while holding the ball





### Gameplay Systems

* Score detection through the hoop
* Scoreboard displayed in the environment
* Travel/Foul detection system
* Foul screen message
* Automatic reset after fouls
* Automatic reset after scoring



### The Game Feel

* Progressive movement acceleration
* Dynamic camera FOV scaling
* Different jump forces
* Charge throw mechanics
* Responsive ball handling



## Controls

Move - WASD

Sprint - Left Shift

Jump - Space

Pick up ball - Left Mouse Click

Charge Throw - Hold Left Mouse Button

Throw ball - Release Left Mouse Button

Dribble - Hold Right Mouse Button

Reset Player Position with Ball - R
